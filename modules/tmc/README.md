# The Magus Class

> An Arcane Warrior Wielding Spell and Steel…

The Magus is a spell-slinging, steel-wielding new class with six subclasses, perfect for mixing and matching magical themes and combat styles.

New Features:

* The Magus class
* **6 subclasses:** Arcane Order, Heaven’s Guard, Knights Stygian, Shadow Court, Sidereal Cabal, Sylvan Circle.
* **30+ new spells** available to the Magus and expanding the spell lists of other classes.
* **20 magic items** every aspiring gish will wish for.
