# Dr Dhrolin’s Dictionary of Dinosaurs

Written by palaeontologists and illustrated by world-famous palaeo-artists, _Dr Dhrolin’s Dictionary of Dinosaurs_ provides everything you could possibly need to fill your world with prehistoric content, or to build an entirely new prehistoric-themed campaign.

In addition to providing heaps of Mesozoic reptiles (dinosaurs, pterosaurs, marine reptiles, etc.), this book also includes plot hooks, immersive real-world environments (with in-game effects, fauna, and flora), realistic behaviour, evolution mutations, taming rules, naming tables, riding rules, and mountains of scientific information about each animal. This is all complemented by optional magical rules for each non-fictional creature, playable dinosaur-folk species, and NPCs to build your own high-fantasy prehistoric setting.
