# Abomination Vaults

Spiteful evil stirs beneath the mysterious lighthouse called Gauntlight. Hideous monsters, deadly traps, unexpected allies, vengeful ghosts, and more await the heroes who dare to enter the sprawling megadungeon called the Abomination Vaults! The Abomination Vaults Adventure Path is a complete Fifth Edition (2024) campaign taking heroes from 1st to 11th level.
